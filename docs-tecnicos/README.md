# 📁 Módulo de Base de Conocimiento e Inteligencia Artificial (RAG)

Este apartado almacena la documentación técnica operativa del puerto y el resultado del procesamiento del modelo de IA.

## 🚀 Componentes Técnicos

1. **`manual_navis_n4.txt`**: Documento de texto plano que simula los procedimientos operativos estandarizados (SOP) y los protocolos de emergencia del sistema internacional de gestión portuaria Navis N4.
2. **`matriz_conocimiento.json`**: Base de datos relacional semántica de tipo clave-valor generada por el cuaderno de IA de **Google Colab**. Clasifica los fragmentos del manual bajo las etiquetas de `maquinaria` y `seguridad` para agilizar las búsquedas en la web app.
